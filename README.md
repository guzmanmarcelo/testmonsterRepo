# testmonsterRepo

This project uses [Selenide]([https://www.selenium.dev](https://selenide.org)), [Java](https://www.java.com/en/) and [Cucumber](https://cucumber.io)

## How to run the tests
There are some ways to execute the tests:

### Using maven

`mvn clean test` <br>

### Using the Cucumber runner
Go to `/src/test/java/`  and open the `TestRunner.java` class. <br>
Select the `Run Test` option
